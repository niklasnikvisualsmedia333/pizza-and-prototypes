# Optionales Eventvideo

Ein Eventvideo ist erst sinnvoll, wenn die finale Datei technisch geprüft wurde.

- bevorzugter Einsatzort: ausschließlich im Pilot-Recap
- nicht gleichzeitig auf Community- und Unternehmensseite einbinden
- kein Autoplay; Controls sichtbar lassen
- ein geprüftes Posterbild verwenden
- `preload="metadata"` oder `preload="none"`
- MP4 und WebM in geeigneten Varianten bereitstellen
- mobile Dateigröße besonders prüfen
- Untertitel oder eine gleichwertige Textalternative vorsehen

Vor der Implementierung Dateiformat, Laufzeit, Rechte, Ton und tatsächliche Größe prüfen.
